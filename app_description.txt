

# **PLUGGPT: COMPLETE UNIFIED PRODUCT SPECIFICATION**

*(Developer-ready. Neutral tone. Ready for Cursor.)*

This document defines the product scope, feature set, branding system, UI structure, and technical expectations for **PlugGPT**, a core feature inside *The Academic Plug* application. Everything here is cohesive and consistent.

---

# **1. Product Summary**

PlugGPT is an academic-focused LLM interface designed for high-school and university students, with an emphasis on IB students. It provides structured academic explanations, writing assistance, guided workflows, and subject-specific tools inside a clean, minimal, responsive tailwind-based UI.

Emphasizes:

* Accurate academic reasoning
* Step-by-step explanations
* Organized, structured outputs
* IB-aligned workflows
* Study productivity features
* Task-specific modes (writing, math, analysis, science, etc.)
* Zero clutter, zero distractions
* Fully responsive SPA design

Dark and light theme options are built-in, switchable via UI toggle.

---

# **2. Core Principles**

* Precision instead of verbosity
* Clear explanations rather than overwriting user work
* Outputs always structured
* Academic integrity compliant
* Modular, expandable features

# **4. Branding, Identity & Global UI Standards (From Academic Plug Style Guide)**

## **4.1 Branding: Colors (Mandatory)**

| Name                         | Hex         | Tailwind Token  | Usage                                                                  |
| ---------------------------- | ----------- | --------------- | ---------------------------------------------------------------------- |
| Primary Accent (AP-Yellow)   | **#FFC107** | `ap-yellow`     | Buttons, active states, links, highlights, accents, subject selections |
| Light Card Background        | **#FFFBEA** | `ap-light-card` | PlugGPT message bubbles, informational cards                           |
| Base Background (Light Mode) | **#F9FAFB** | `bg-gray-50`    | Default light background                                               |
| Base Background (Dark Mode)  | **#111827** | `bg-gray-900`   | Default dark background                                                |
| Text Primary                 | **#1F2937** | `text-gray-900` | Standard light-mode text                                               |

Include Tailwind custom classes for `ap-yellow` and `ap-light-card`.

## **4.2 Typography**

* Font: **Inter**, sans-serif
* Always use clean, neutral academic typography
* No decorative fonts

## **4.3 Aesthetics**

* **Extremely rounded corners:** `rounded-xl` to `rounded-2xl`
* **Soft elevated shadows:** `shadow-lg` or `shadow-xl` on cards and tool sections
* **Line icons:** preferably Lucide

## **4.4 Responsiveness**

* Fully responsive SPA using Tailwind breakpoints (`sm: md: lg:`)
* All components gracefully collapse into mobile layout

## **4.5 Logo**

* Logo file: **`BlackBGMain.png` for dark mode**  **`WhiteBGMain.png` for light mode**
* Used in header, sidebar, and landing states

## **4.6 Theme System**

* User can **switch between light and dark mode**
* Tailwind dark mode class approach recommended

# **5. System Architecture Overview**

## **5.1 Frontend**

* Built in **Next.js** or React (developer choice)
* SPA-style workflow
* Tailwind CSS for all styling
* Markdown rendering for LLM responses
* Sidebar navigation
* No login required in v1 (localStorage saves)

## **5.2 Backend**

* Node/Express or Python (FastAPI)
* Connect to a **free compatible LLM API**
* All feature modules implemented as separate backend functions
* Rewriter layer ensures formatted, structured outputs

# **7. PlugGPT Chat Interface (Visual/UI Requirements)**

## **Chat Layout**

* Standard two-column chat stream
* Scrollable conversation feed
* Export options visible (copy, save, etc.)

## **Chat Bubbles**

### **User Message Bubble**

* Background: `ap-yellow/30` (light yellow tint)
* Rounded-xl or rounded-2xl
* Right-aligned

### **PlugGPT Message Bubble**

* Background: `ap-light-card`
* Must contain a **label** at the top:

  * Bold text “PlugGPT”
  * AP-yellow text color
  * Small icon (sparkles/zap) next to it
* Left-aligned

## **Input Bar**

* Persistent at bottom
* Border accented in **AP-yellow**
* Send icon (Lucide)

## **Theme Support**

* Text, bubbles, borders must auto-adapt to dark mode
